# Clinical safety hazard log

Practices follow ISO 14971 principles; this is not a claim of conformity. Residual risk must be accepted by an
accountable person before any clinical use (Phase 6). Status reflects the Phase 2 prototype.

**Intended use (draft):** a personal quick-reference aid for a registered remote area nurse, supplementing the current
approved CARPA manual, local procedures and medical officer consultation. It does not diagnose, decide treatment,
authorise medicines or contact anyone.

**Foreseeable misuse:** relying on it instead of the manual; using demo/template content as guidance; using outdated
content; assuming a contact was made; sharing a device without clearing the session.
