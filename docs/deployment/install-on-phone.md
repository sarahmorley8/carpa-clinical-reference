# Installing the app on your phone

The app must first be hosted on a secure (https) website — see the hosting decision in Phase 4. Then:

## iPhone (Safari)

1. Open the app's web address in **Safari** (not Chrome or another browser — iPhones only install web apps from Safari).
2. Tap **I understand** on the disclaimer.
3. Tap the **Share** button (square with an arrow), then **Add to Home Screen**, then **Add**.
4. Open the app **from the new home-screen icon** and wait until the Home screen shows **✓ Offline ready**.
5. Test it: turn on **Airplane Mode**, close the app fully (swipe it away), and open it again from the icon. It should
   open normally. Turn Airplane Mode off afterwards.

## Android (Chrome)

1. Open the app's web address in **Chrome**.
2. Tap **I understand**.
3. Tap the **⋮** menu → **Install app** (or **Add to Home screen**).
4. Open it from the new icon and wait for **✓ Offline ready**.
5. Test with **Airplane mode** as above.

## Keeping it up to date

- Open the app while you have internet every so often. Updates download and are checked automatically.
- When an update is ready you will see **"An update has been downloaded and checked"**. It is only applied when you
  tap **Apply update now**, and only when no patient session is open.
- If the app has not managed to check for updates for more than 30 days, it says so on the Home screen and in
  Settings.
- **Settings → Offline readiness** shows whether every file is saved, when updates were last checked, and lets you
  re-check.

## Things to know

- iPhones do not vibrate for web apps, and may mute timer sounds in silent mode. Keep the app open on screen while a
  timer runs.
- Deleting the home-screen icon (or clearing Safari website data) removes the offline copy; reinstall while online.
